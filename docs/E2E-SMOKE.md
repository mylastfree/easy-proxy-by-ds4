# 真实浏览器 E2E 冒烟清单

> 【M-4·审计修复】单元/护栏测试全部依赖手写 chrome mock，真实浏览器的行为差异
> （chrome.proxy 语义、存储配额、SW 生命周期）不在其覆盖范围内。本清单是发布前
> 的最低限度人工冒烟：每次发布（版本号变更）前逐项执行并勾选，全部通过才打包。
>
> 环境：Chrome 稳定版（不低于 manifest 的 minimum_chrome_version），普通窗口 +
> 隐身窗口各验证一次关键项。

## 准备

- [ ] 本地代理可用（如 127.0.0.1:10808 的 SOCKS5 / HTTPS 代理），可访问外网
- [ ] `node tools/package.js` 产出 dist/，以「加载已解压的扩展程序」加载 dist 目录
- [ ] 打开 chrome://extensions 确认无报错（service worker 处于活动状态）

## 安装与升级

- [ ] 全新安装：打开 popup，全部字段为默认值；开关默认关闭
- [ ] 卸载后重装（同一账号）：云端已有配置不被默认值覆盖（V-04 真实验证）
- [ ] 覆盖旧版本目录升级：用户已填地址/端口/绕过列表原样保留

## 启用与生效

- [ ] 填入代理地址端口，启用，保存 → 图标转绿，状态条显示「代理已生效」
- [ ] 连接测试「测试当前出口」→ 出口为代理服务器出口；界面出现第三方出口知情提示
- [ ] 「对比直连出口」→ 直连出口与本机网络一致，对比后配置自动恢复
- [ ] 绕过列表填 `.lan`，访问内网地址直连生效

## 禁用与接管

- [ ] 关闭开关 → 图标变灰/红，状态「未启用代理（直连）」，网页可正常访问
- [ ] 用另一个扩展（如 Proxy SwitchyOmega）接管代理 → 本扩展显示「被外部接管」，
      不发生夺权；本扩展未启用时点保存/开关亦不得清掉对方的配置
- [ ] 删除接管方扩展 → 本扩展控制权恢复，界面状态如实刷新

## 边界与异常

- [ ] 填入非法值（空端口、`example.com:8080:90`、超范围端口）→ 保存被拒绝并如实提示，
      图标不转绿
- [ ] 粘贴超过 8KB 的超长绕过列表 → 提示「已存于本地（不跨设备同步）」，重开 popup
      列表仍在；随后关闭代理 → 长列表不丢失
- [ ] 停掉代理软件 → 连接测试报错如实呈现，图标转红；恢复代理软件后重测恢复
- [ ] 开发者工具中确认：`chrome.storage.local` 只有预期键；无 `eval`/远程代码加载

## 收尾

- [ ] 移除扩展：设置随扩展清除，浏览器代理恢复系统默认（chrome://settings 确认）
- [ ] 全部通过后：`git tag v<version>` 前再跑一次 `npm run mutation`
